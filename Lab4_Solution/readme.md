Креирајте Django апликација за менаџирање на фитнес центар.

Секој тренинг се карактеризира со назив, слика, тренер, категорија (кардио, сила, јога, HIIT, пилатес, крос-фит, истегнување), ниво (почетно, средно, напредно), траење (во минути), капацитет (максимален број на учесници) и цена.

За секој тренер се знае: име, земја и град во кој се наоѓа, години на искуство и официјален вебсајт.

Потребно е да овозможите додавање на објекти преку Админ панелот. Со користење на Bootstrap рамката креирајте 2 темплејти за приказ на информациите:

/index/ – приказ на сите тренинзи (слика, назив, цена) во grid layout

/trainings/add/ – форма за додавање на нов тренинг; по успешно зачувување корисникот се пренасочува на /index/

__________

Create a Django application for managing a fitness center.

Each training is characterized by a name, image, trainer, category (cardio, strength, yoga, HIIT, pilates, crossfit, stretching), level (beginner, intermediate, advanced), duration (in minutes), capacity (maximum number of participants) and price.

For each trainer the following is known: name, country and city, years of experience and official website.

Objects should be added via the Admin panel. Using the Bootstrap framework, create 2 templates for displaying the information:

/index/ – display all trainings (image, name, price) in a grid layout

/trainings/add/ – form for adding a new training; after successful save the user is redirected to /index/
